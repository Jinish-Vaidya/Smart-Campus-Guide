# All Models – Smart Campus Guide

This folder contains the pre-trained Keras models that were fine-tuned using transfer learning for the Smart Campus Guide project.  
Each model includes training, evaluation, and result files.

## VGG16 (Reference Model)
VGG16 is the most complete model in this project and should be checked first.  
It contains:
- Heatmap visualizations for interpretability  
- A complete PDF report of results and analysis  
- Training on multiple epochs  
- Full training, evaluation, and result tracking
